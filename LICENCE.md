## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\FortniteSkinSwapper\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Key to toggle menu |
| `auto_attach` | Boolean | `true` | Auto-attach on startup |
| `process_name` | String | `"FortniteClient-Win64-Shipping.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Minimize detection risk |
| `log_level` | String | `"info"` | `"debug"`, `"info"`, `"error"` |
